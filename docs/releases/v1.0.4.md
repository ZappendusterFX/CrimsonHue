# CrimsonHue 1.0.4

Reduces rapid local-light fluctuations during movement and restores the selected
own-lantern reduction while the equipped lamp swings.

Changes since the public 1.0.1 release:

- Local output now uses two-stage smoothing after spatial mapping. The selected
  response still reaches 63% of a steady change in the same time; short flashes
  can be softer or peak slightly later. Quick, Balanced, Calm and saved Custom
  values are preserved.
- Own-lantern recognition accepts the current cone pair and recorded swinging
  poses. It checks the known emission pair near the player instead of requiring
  a narrow forward-facing pose. **Own lantern** remains 10% in Recommended;
  0% removes the recognized pair and 100% retains ordinary spotlight strength.

Unrelated world lights and spell effects keep their existing weights. Room
calibration, saved settings, Ambient and CDT's fresh-clear visibility rules are
unchanged. Incomplete or ambiguous pairs retain ordinary spotlight weight; the
recognizer is a bounded metadata signature, not a general engine ownership ID.

Use **CDT 2.2.7** for the complete update on game patch 2.04.05. Its independent
visibility-cache fix prevents retired light positions from crowding out new
queries during changing effects. Only Hue needs replacing if CDT 2.2.7 is
already installed.

Validation: 133 Core tests, exact packaged hidden-controller smoke, ZIP checks
and actual packaged-Core replays of the preserved recordings pass. The owner
reports that the updated in-game lighting is now very good. This is user
feedback, separate from synthetic tests and offline measurements; see
[motion-response evidence](../MOTION-RESPONSE-20261103.md) and
[lantern-motion evidence](../LANTERN-MOTION-20261103.md).

Close the game and install **CrimsonHue-1.0.4-asi-win-x64.zip** yourself through
your mod manager. .NET 8 Desktop Runtime x64 remains required separately.
Installation is exclusively the owner's responsibility.
