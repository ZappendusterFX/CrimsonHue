# CrimsonHue 1.0.4

Fixes own-lantern recognition during walking, turning and swinging motion.
The current game reports a changed pair of lantern light cones; the previous
recognizer also required a narrow forward-facing pose. This could bypass the
saved Own lantern reduction and apply full spotlight strength instead.

Recognition now checks the measured warm emission, one complete known cone pair
and a bounded volume around the player. The existing **Own lantern** control
works for the recorded poses: Recommended stays at 10%, 0% removes the recognized
pair, and 100% retains its ordinary spotlight contribution. Unrelated world lights
and spell effects keep their existing weights. No settings are reset.

The two-stage response from 1.0.3 remains. CDT's fresh-clear visibility rules,
Ambient and all other mapping behavior are unchanged. Incomplete or ambiguous
pairs still receive ordinary spotlight weight; this is a conservative metadata
signature, not a general engine ownership ID.

Keep **CDT 2.2.7**. Only Hue needs this update if that companion is already
installed. Validation uses the existing recordings and synthetic checks;
see [lantern-motion evidence](../LANTERN-MOTION-20261103.md). Physical appearance
of the new package still requires owner acceptance.

Close the game and install **CrimsonHue-1.0.4-asi-win-x64.zip** yourself through
your mod manager. .NET 8 Desktop Runtime x64 remains required separately.
Installation is exclusively the owner's responsibility.
