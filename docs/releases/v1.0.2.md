# CrimsonHue 1.0.2

Local validation candidate, never published. Its immutable ZIP and replay evidence
are preserved. Superseded by 1.0.3 with the same smoothing implementation and
updated companion guidance for the subsequently demonstrated CDT cache fix.

Reduces rapid local-light fluctuations during movement by replacing the single
output smoothing stage with two stages. The existing response setting still
reaches 63.2% of a steady change in the selected time; Quick, Balanced, Calm and
saved Custom values remain unchanged. Spatial targets, source weights and room
calibration are preserved.

The change is confined to Hue. CDT 2.2.6 continues to provide the raw neutral
stream and fresh visibility decisions. Unknown, blocked and stale sources still
add no new contribution. The previous local output may fade briefly; losing the
whole local feed immediately clears both output and history. Ambient keeps its
independent response and removal rules.

The existing quiet-corridor recording and synthetic short flashes are compared
in [motion-response validation](../MOTION-RESPONSE-20261103.md). These are offline
and synthetic results, not a physical-lamp guarantee. Brief flashes can peak
slightly later, and slow scene changes remain visible. No combat-effect detector
or source-identity heuristic is added.

Install only **CrimsonHue-1.0.2-asi-win-x64.zip** for this update if CDT 2.2.6 is
already installed. Close the game and install the complete package yourself
through your mod manager. .NET 8 Desktop Runtime x64 remains required separately.
Installation is exclusively the owner's responsibility.
