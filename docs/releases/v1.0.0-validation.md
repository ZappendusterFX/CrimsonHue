## Scope and publication

The owner has used private builds in-game with real lamps. The final versioned
ZIP was not installed or physically tested in this release operation; no game
input, installed module, real settings or lamp output was changed. Synthetic
input/GPU checks do not prove all game input routes, HDR displays, mod managers
or other hardware. Existing process-lifetime and bridge cleanup limits remain.

Collision is not optical visibility: cages or colliding glass may falsely exclude
visible lamps; noncolliding occluders may fail to block. The release explicitly
documents that limitation. Renderer-contribution research is not shipped.
